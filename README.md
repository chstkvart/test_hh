# Мини-синхронизатор заявок

Веб-сервис забирает «сырые» заявки с API источника (адрес задаётся в `SOURCE_URL`), нормализует телефоны, удаляет дубли и отдаёт результат в JSON.

**Живой URL:** https://orders-sync-269t.onrender.com/result

## Эндпоинты

| Путь | Описание |
|------|----------|
| `GET /result` | Результат синхронизации (также доступен на `/`) |
| `GET /health` | Health check |

Пример ответа:

```json
{
  "clients": [
    { "name": "Иван П.", "phone": "+79991234567", "email": "", "amount": 5000 }
  ],
  "stats": { "received": 17, "unique": 8, "duplicates_merged": 5, "invalid_dropped": 4 }
}
```

## Логика

1. **Загрузка** — GET на источник, до 3 попыток при сбое, ошибки пишутся в лог. Если источник недоступен, отдаётся последний успешный результат.
2. **Нормализация телефона** — из строки берутся только цифры:
   - 11 цифр, начинается с `7` или `8` → `+7XXXXXXXXXX`;
   - 10 цифр, начинается с `9` → дополняется до `+79XXXXXXXXX`;
   - всё остальное — невалидно и отбрасывается (`invalid_dropped`).
3. **Дедупликация по телефону** — остаётся запись с максимальным `amount`, при равенстве — более поздняя по `created_at`.
4. **Статистика** — `duplicates_merged = received - invalid_dropped - unique`.

**Идемпотентность:** результат каждый раз детерминированно пересчитывается из источника, состояние не накапливается — повторная синхронизация не плодит дубли и возвращает тот же ответ.

## Секреты и конфигурация

Секретов в коде и репозитории нет. Адрес API источника считается секретом и читается только из переменной окружения:

| Переменная | Обязательна | По умолчанию |
|------------|-------------|--------------|
| `SOURCE_URL` | да | — |
| `PORT` | нет | `8000` |

- **Локально** — файл `.env` (шаблон: `.env.example`). Он в `.gitignore` и `.dockerignore`, поэтому не попадает ни в git, ни в Docker-образ.
- **На Render** — Environment Variables в панели сервиса; в `render.yaml` переменная объявлена с `sync: false`, значение в репозитории не хранится.

Без `SOURCE_URL` сервис не стартует и пишет понятную ошибку.

## Запуск

```bash
cp .env.example .env   # вписать реальный SOURCE_URL

# Python 3.11+, без внешних зависимостей
python app.py

# или Docker
docker build -t orders-sync .
docker run -p 8000:8000 --env-file .env orders-sync
```

Открыть: http://localhost:8000/result

## Деплой (CI/CD)

Render Blueprint (`render.yaml`): Docker-сервис с `autoDeploy: true` — каждый push в `main` пересобирает образ и выкатывает новую версию. Health check — `/health`.

## Стек

Python 3.12 (стандартная библиотека: `http.server`, `urllib`, `json`), Docker, Render.
